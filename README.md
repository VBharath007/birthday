# Happy Birthday, Kanmani! 🎂✨

A heartfelt, interactive Next.js birthday experience crafted with love.

## ✨ Features
- **Oru Chinna Kelvi**: Playful evasive "Do you love me?" question card with interactive bouncing "No" button and celebratory confetti.
- **Chapter 1: The Birthday Party**: Surprise balloon popping gifts with custom wishes and animations.
- **Chapter 2: Sweet Memories**: Photo memories gallery celebrating beautiful moments.
- **Chapter 3: Heartfelt Letter**: A poetic handwritten birthday letter with emotional wishes.
- **Chapter 4: Make a Wish**: Interactive birthday cake candle blowing ceremony.
- **Audio Experience**: Romantic background music integration.

## 🛠️ Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS, Canvas Confetti
- **Icons**: Lucide React
- **Language**: TypeScript

## 🚀 Getting Started
```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.
